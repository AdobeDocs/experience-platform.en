These five files are source material for continuing the ADLM documentation restructure. Use them to understand the rationale, architecture, stakeholder context, confirmed decisions, and open dependencies.

The main objective is to restructure ADLM documentation from feature-centered pages into a customer-centered documentation system. The guiding principles are: single source of truth for shared concepts, customer-intent-based navigation, reduced duplication, clear separation between Privacy Service, Data Hygiene, Record Delete, Dataset Expiration, TTL, timelines, quotas, and exception guidance.

Treat the timeline files chronologically. The later publication and review strategy file supersedes the earlier timeline file where they differ. Earlier open SME questions about timeline publication should be treated as historical unless repeated in the later file. Timeline canonicalization is largely validated and published or ready to consolidate around.

Do not treat every open question as blocking all work. Privacy Service vs Data Hygiene endpoint boundaries and quota entitlement vs enforcement wording remain unresolved and require stakeholder confirmation before public restructuring decisions are made.
