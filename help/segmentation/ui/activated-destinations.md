# Activated destinations

>[!AVAILABILITY]
>
>Activated destinations is in **closed beta**. For more information on enablement, contact Adobe Customer Care.

Activated destinations shows a list of all the destinations the specific audience has been activated to. This helps you consolidate, in an audience-centric manner, per-destination details such as schedule, recent flow-run history, and destination status.

## Access {#access}

To access activated destinations, find the audience you want to get the activated destination information for within [Audience Portal](/help/segmentation/ui/audience-portal.md), then select **[!UICONTROL Activated destinations]**.

IMAGE

## Destinations {#destinations}

The activated destinations page appears, displaying a read-only list of the activated destinations for the specified audience, with details including the destination name, destination type, schedule, last dataflow run date, and last dataflow run status.

IMAGE

| Field | Description |
| ----- | ----------- |
| Destination name | The name of the destination. |
| Destination | The type of destination. |
| Schedule | The schedule which the audience activates to the destination. |
| Last Dataflow Run Date | The date that the last dataflow run ran. |
