# Create a dynamic segment in the Experience Platform UI

The following video is intended to support your understanding of creating dynamic segments. It shows an example customer experience followed by a quick tour of key features in the [!DNL Platform] interface. To learn more about segmentation and how to create segments in the UI, please read the [Audience Builder guide](../ui/audience-builder.md).

If you are interested in creating a segment using the Segmentation API, please read the [create a segment API guide](../tutorials/create-a-segment.md).
